1) How To Use agrep In Practice

Typical run pattern by an agent/operator:

  1. Formulate intent query in NL or explicit terms.
  2. Pick domain (code, legal, docs, logs, or auto).
  3. Run with --show-plan first to inspect query expansion and boosts.
  4. Collect top results in table format for triage, then jsonl for machine pipelines.
  5. Apply include/exclude/context flags to tighten scope and then take action.

3) How To Make Sense Of Hits

FieldMeaningHow to use it
scoreAggregate relevance score.Start triage from highest score; stop when relevance drops below your threshold.
source_typeClassified domain (code/legal/docs/logs).Route work to right workflow (refactor, contract review, policy check, incident response).
path:anchorExact location in file.Open precise line quickly for edit/review.
score_breakdownPer-signal contribution (term/path/domain/intent).Debug why a match ranked high or low.
signalsConfidence/parse/generated flags.Filter low-confidence or generated-only hits before decisions.

4) End-to-End Decision Flow (When a Hit Appears)

  1. Validate intent via nl_plan from --show-plan.
  2. Inspect top 5 hits by score.
  3. Confirm domain correctness (source_type and file path semantics).
  4. If code hit: identify definition/callsite and open follow-up query for references.
  5. If legal hit: capture clause ID and related sections for reviewer packet.
  6. If logs hit: correlate neighboring timestamps and routes, then escalate incident if needed.
  7. Apply narrowing flags (--include, --exclude, --context-lines) until false positives are acceptable.
  8. Only then perform edits, policy action, or incident updates.

6) Recommended Production Runbook

  1. Always run first with --show-plan in CI/debug mode.
  2. Use table for analyst triage, then repeat in jsonl for automation.
  3. Define domain-specific score cutoffs (example: code ≥ 0.35, legal ≥ 0.50).
  4. Persist top hits and plan into artifact logs for auditability.
  5. On high-risk keywords (auth, delete, terminate, breach), require human sign-off.
